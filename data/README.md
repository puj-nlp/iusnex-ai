# Datos

- `raw/`: fuentes originales sin modificar.
- `external/`: datos provenientes de terceros.
- `interim/`: resultados intermedios de limpieza y transformación.
- `processed/`: conjuntos preparados para análisis y modelado.

Los datos se excluyen de Git. Documentar para cada fuente su procedencia,
licencia, fecha, esquema y método de acceso. Mantener datos personales y
documentos jurídicos reservados fuera del sitio público.
